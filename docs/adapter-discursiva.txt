Usamos adaptador de objeto (composicao) porque o Java nao tem heranca multipla de classes: o adaptador precisa implementar a interface CalculadoraFrete e, ao mesmo tempo, usar a classe do fornecedor. Com composicao, o adaptador recebe o Adaptee pelo construtor, entao da para trocar a implementacao ou passar uma subclasse dele sem alterar o adaptador. Tambem evita expor os metodos do fornecedor na interface publica do adaptador, e as classes dos fornecedores continuam sem modificacao.
